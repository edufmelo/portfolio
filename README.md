# Portfólio Pessoal

Este repositório contém meu portfólio pessoal. Ele foi criado originalmente com HTML, CSS, JavaScript e jQuery e, em 2026, foi migrado para React para acompanhar minha evolução como desenvolvedor. A migração, a revisão do código e parte das melhorias de responsividade e acessibilidade contaram com o apoio de Inteligência Artificial.

O projeto apresenta minhas habilidades, alguns trabalhos recentes, projetos pessoais e experiências acadêmicas e profissionais.

## Tecnologias utilizadas

- React;
- React Icons;
- Vite;
- HTML5;
- CSS3;
- JavaScript;
- Intersection Observer API.

O Vite fornece o servidor utilizado durante o desenvolvimento e gera a versão otimizada do site para publicação. As animações de entrada são controladas pelo React com a Intersection Observer API do navegador.

## Apoio de Inteligência Artificial

Foi utilizada IA como ferramenta de apoio durante o desenvolvimento, principalmente para revisar a estrutura, sugerir melhorias, auxiliar na migração para React e identificar problemas de responsividade. As decisões sobre conteúdo, identidade visual e resultado final permanecem sob responsabilidade do autor.

## Arquivos de configuração

- `package.json`: descreve o projeto, os comandos disponíveis e as bibliotecas utilizadas;
- `package-lock.json`: registra as versões exatas dessas bibliotecas para que a instalação seja reproduzida da mesma forma em outras máquinas. Ele é gerado automaticamente pelo npm e deve permanecer no repositório.

## Como executar

```bash
npm install
npm run dev
```

O principal objetivo deste portfólio é mostrar meu progresso como desenvolvedor, com foco na criação de interfaces responsivas e interativas. O conteúdo continuará sendo atualizado conforme adquiro novas habilidades e tecnologias.
